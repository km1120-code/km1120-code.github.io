LEARNING THEORY / EXPLANATORY NOTE

A finite-class generalization bound, one step at a time

4 min read · Companion to a runnable educational example

Training error is computed from a finite sample. Population error averages over the distribution that generates examples. The first is observable; the second is usually unknown. Our small threshold example makes both available.

1. Fix the model before sampling

Choose 41 thresholds on [0, 1]. A classifier predicts one whenever the input exceeds its threshold. Inputs are uniform, and the label of the threshold at 0.5 is independently flipped with probability η = 0.1.

R(t) = η + (1 − 2η) |t − 0.5|

The interval between t and 0.5 has length |t − 0.5|. On that interval the classifier disagrees with the noiseless rule. This gives the exact population error above.

2. Control one empirical average

For a fixed threshold, each sample error is a Bernoulli variable. Hoeffding’s inequality bounds the probability that its average differs from its expectation by more than ε.

Pr(|R̂(t) − R(t)| > ε) ≤ 2 exp(−2nε²)

3. Control all hypotheses together

Apply the union bound to H fixed hypotheses, then set the resulting upper bound equal to δ. With probability at least 1 − δ, every hypothesis satisfies:

|R̂(t) − R(t)| ≤ √[log(2H/δ) / (2n)]

This remains useful when the final hypothesis is selected using the same sample, because the event controls the whole fixed class at once. The guarantee here is for one fixed sample size.

4. Interpret the plot carefully

The example repeats each sample size 128 times. The empirical 95th percentile provides a descriptive comparison with the theoretical upper bound. It is not itself a confidence bound. Finite Monte Carlo observations illustrate the result; the mathematical inequality establishes it.
