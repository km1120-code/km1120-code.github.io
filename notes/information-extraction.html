INFORMATION EXTRACTION / EXPLANATORY NOTE

From a sentence to entities, relations, and evidence

4 min read · Companion to a runnable educational example

Information extraction converts statements in text into structured records. Two basic tasks are identifying entity mentions and assigning relations between them. A useful evaluation keeps the text evidence attached to each prediction.

1. Preserve the evidence

An entity mention has a span and a type. In “Amara Okafor works at Cedar Labs in Kigali.”, the baseline recognizes a person, an organization, and a location. Spans use half-open character offsets: the start is included, the end is excluded.

Entity = (start, end, type)
Relation = (head span, relation type, tail span)

The extracted relation is (Amara Okafor, WORKS_FOR, Cedar Labs). The baseline does not infer a location relation from an unsupported phrase. It retains only the direct relation matched by its rule.

2. Separate predictions from annotations

The example includes 12 independently annotated synthetic sentences. A fixed gazetteer recognizes known names, and a few verb patterns propose relations between adjacent mentions. The gold annotations are authored separately; they are not generated by the extraction rules.

The fixture includes unseen names, paraphrases, negation, and uncertain statements. In the interactive example, switch between the baseline output and the gold annotation to inspect both successful matches and omissions.

3. Define an exact match

An entity is correct only when both boundaries and its type match. A relation is correct only when its type, direction, and both endpoint spans match. Reversing the head and tail is an error.

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2TP / (2TP + FP + FN)

Counts are aggregated over documents before computing these micro scores. Duplicates within one document count once. Identical offsets in different documents remain distinct examples.

4. Read the limitations with the result

On this fixture, the baseline finds 28 of 30 entity mentions and 7 of 10 relations, with no false positives. These are observations on a small fixture created alongside the baseline. They do not estimate performance on an independent test set.

Unseen names are missed by the gazetteer. Paraphrases such as “co-founded” are outside the supported relation patterns. The example exposes these limitations directly instead of adding unsupported predictions.
