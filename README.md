# Kwame Mensah — academic homepage demo

A responsive, dependency-free static academic homepage demonstration.

Website: https://km1120-code.github.io/

Source: https://github.com/km1120-code/km1120-code.github.io

The profile
is explicitly fictional. It contains three runnable educational project
archives and three explanatory notes. No degree, affiliation, paper, or real
person's project history is asserted.

## Preview

```bash
python -m http.server 8765 --bind 127.0.0.1
```

Open `http://localhost:8765/`. All assets, fonts, figures, and source downloads
are local. No analytics, external script, API key, or build system is required.

## GitHub Pages

For a user site, create a **public** repository named `<username>.github.io`
on the intended account, after confirming the account's actual username. Put
the contents of this directory at the repository root. In the repository's
**Settings → Pages**, use **Deploy from a branch → main → / (root)**.
The resulting address is `https://<username>.github.io/`.

The `.nojekyll` file tells Pages to serve these static files without Jekyll.
Internal links are relative, so a project-site deployment also works. The configured GitHub account is `km1120-code`. There is no custom domain.

Official deployment reference:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Edit

- `index.html`: profile copy, interests, project list, and homepage sections.
- `assets/data/profile.json`: editable profile copy and unconfirmed academic-background fields.
- `assets/css/style.css`: color tokens, typography, and responsive layouts.
- `assets/js/site.js`: saved theme preference, section navigation, channel demo.
- `projects/`: independent pages with source and experiment settings.
- `notes/`: explanatory notes linked to each experiment.
- `assets/img/`: actual plots generated by the accompanying Python examples.
- `downloads/`: complete project source archives, including data and tests.

The portrait is an original GPT Image 2 illustration of a fictional young
adult holding a cheetah cub. Its generation provenance is recorded in the source and About page. The introduction uses the provided origin (Rwanda) and research interests.
Age, institution, department, position, and OpenReview URL remain unset until
provided. Unfilled background fields are omitted from the visible biography. Do not place account passwords, 2FA seeds, tokens, or private
research files in this repository.

The prototype includes a visible fictional-profile label and `noindex` metadata.
IE means Information Extraction. The featured NLP example includes entity and relation extraction with exact-match evaluation.
