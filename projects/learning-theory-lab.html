Learning Theory Lab

A finite hypothesis class, a known data distribution, and a direct comparison between empirical risk and a uniform-convergence bound.

The question

How quickly does the gap between empirical and population risk decrease as the sample grows?

The experiment

Compare 41 fixed threshold classifiers on a synthetic distribution with independent label noise. Compute each classifier’s exact population risk, then repeat sampling 128 times at each training-set size.

Scope and interpretation

The plotted trial percentiles are descriptive Monte Carlo statistics. They are not confidence intervals, and the probability guarantee applies separately at each sample size.

import numpy as np

def population_risk(thresholds, noise=0.1):
    thresholds = np.asarray(thresholds, dtype=float)
    if np.any((thresholds < 0) | (thresholds > 1)) or not 0 <= noise <= 0.5:
        raise ValueError('Thresholds must be in [0, 1], noise in [0, 0.5].')
    return noise + (1 - 2 * noise) * np.abs(thresholds - 0.5)

def empirical_risks(x, y, thresholds):
    x, y, thresholds = np.asarray(x), np.asarray(y), np.asarray(thresholds)
    if x.ndim != 1 or y.shape != x.shape or len(x) == 0:
        raise ValueError('A nonempty one-dimensional sample is required.')
    return np.mean((x[:, None] >= thresholds[None, :]) != y[:, None], axis=0)

def uniform_bound(n, hypotheses, delta=0.05):
    if n <= 0 or hypotheses <= 0 or not 0 < delta < 1:
        raise ValueError('Positive n and class size, and delta in (0, 1), required.')
    return np.sqrt(np.log(2 * hypotheses / delta) / (2 * n))
